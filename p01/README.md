# Catatan Kesalahan Program C++

| No. | File | Jenis Kesalahan | Pesan yang Muncul | Cara Mengetahuinya |
|---|---|---|---|---|
| 1 | `k1_sintaks.cpp` | **Syntax error**, kesalahan pada penulisan atau tata bahasa dalam kode program. | `expected a ';'` | Setelah menjalankan proses compile. Compiler menunjukkan bahwa terdapat kesalahan pada baris `std::cout`, karena sebelumnya `int nilai = 80` belum diakhiri dengan tanda titik koma (`;`). |
| 2 | `k2_nama.cpp` | **Kesalahan nama variabel**, kesalahan karena nama variabel yang digunakan tidak dikenali oleh program. | `Identifier "Nilai" is undefined` dan `Identifier "bonus" is undefined` | Setelah menjalankan proses compile. Compiler menunjukkan bahwa terdapat kesalahan pada baris `std::cout` yang menggunakan `Nilai`, karena nama variabel tersebut berbeda dengan variabel `nilai` yang sudah dibuat sebelumnya dan karena C++ membedakan huruf besar dan kecil. Selain itu, variabel `bonus` juga digunakan tanpa dibuat terlebih dahulu. |
| 3 | `k3_runtime.cpp` | **Kesalahan runtime**, kesalahan yang terjadi saat program sedang dijalankan. | Tidak ada pesan error saat compile, tetapi program berhenti saat dijalankan ketika jumlah mahasiswa diisi `0`. | Setelah menjalankan proses compile. Program berhasil di-compile tanpa error dan warning. Namun, saat program dijalankan dan jumlah mahasiswa diisi `0`, program berhenti karena terjadi pembagian dengan nol pada perhitungan `total / jumlah_mahasiswa`. |
| 4 | `k4_logika.cpp` | **Kesalahan logika**, kesalahan pada cara atau proses perhitungan program sehingga program menghasilkan output yang tidak sesuai dengan hasil yang seharusnya. | Tidak ada pesan error. Program berjalan dengan normal, tetapi menghasilkan rata-rata `81`, bukan `81.67`. | Setelah menjalankan program dan melihat hasil rata-rata yang ditampilkan. Hasil yang muncul adalah `81`, padahal perhitungan dari nilai tugas `80`, UTS `75`, dan UAS `90` seharusnya menghasilkan rata-rata `81.67`. Kesalahan terjadi karena hasil penjumlahan tersebut masih berupa bilangan bulat sehingga bagian desimalnya terbuang. |
