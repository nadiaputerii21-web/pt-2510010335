# P03 — Ekspresi dan Operator

| No. | Nama File | Pembahasan |
|---|---|---|
| 1 | `operator.cpp` | Mempelajari operator aritmetika, yaitu penjumlahan, pengurangan, perkalian, pembagian, dan sisa bagi. Pembagian dua bilangan `int` membuang bagian pecahan, sedangkan `double` dapat menghasilkan bilangan desimal. Operator `%` hanya digunakan untuk bilangan bulat. |
| 2 | `prioritas.cpp` | Mempelajari urutan pengerjaan operasi berdasarkan prioritas dan asosiativitas operator. Operasi dalam tanda kurung dikerjakan terlebih dahulu. Perkalian, pembagian, dan sisa bagi memiliki prioritas lebih tinggi daripada penjumlahan dan pengurangan. |
| 3 | `campuran.cpp` | Mempelajari pengaruh tipe data `int` dan `double` terhadap hasil perhitungan rata-rata. Penggunaan `double` atau `static_cast<double>` membantu mempertahankan bagian pecahan dalam pembagian. |
| 4 | `sinilai_v02.cpp` | Menghitung nilai akhir mahasiswa berdasarkan bobot kehadiran 10%, mingguan 45%, UTS 25%, dan UAS 20%. Program juga menghitung rata-rata sederhana serta menampilkan nama, NPM, nilai akhir, dan rata-rata mahasiswa. |
